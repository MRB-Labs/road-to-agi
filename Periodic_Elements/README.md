# Periodic Elements — Photograph Database

118 identified elements · 92 source photographs · 92 AI-assisted retouches

Extract the ZIP, then double-click **index.html** to browse offline. Keep the folders beside index.html. No installation, internet connection or server is required.

- **photos/**: retouched PNGs, named atomic-number_symbol_name. Light neutral gray background requested consistently; subtle lighting and shadows vary.
- **originals/**: original downloaded source photographs, unmodified.
- **elements.csv**: spreadsheet-friendly index (UTF-8 with BOM).
- **elements.json**: structured index for code.
- **elements.sqlite**: SQLite database, table `elements`, atomic_number primary key.
- **CREDITS.md**: individual sources, credits and license information.

## What the pictures mean

Pictures show particular specimens, not a unique appearance shared by every sample of an element. Allotropes, oxide films, surface finish, lighting and storage affect appearance. Containers and protective liquids are retained. Gas discharge photos show electrically excited gases; their glow is not their appearance in ordinary room light. Chlorine is shown liquefied under pressure. Berkelium is a solution, not visibly pure metal. Some radioactive-element images are historical or microscopic.

## Retouching

The built-in image editor was instructed to replace the backdrop with light neutral gray #F3F4F4, center the specimen, preserve containers and physical appearance, and add no labels or new features. AI-assisted editing is not pixel-preserving: fine textures, outlines, shadows and glass may differ. Use originals as the documentary record; edited versions are presentation assets. Output pixel size does not imply extra photographic resolution. Original and edited dimensions are recorded separately.

## Coverage and omissions

Every recognized element from Hydrogen (1) to Oganesson (118) has a database entry. Empty image paths mean a usable photograph was not included, not that the element does not exist or that no photograph exists anywhere. The status and description fields distinguish missing sample photos, excluded illustrations or compounds, download failures, and photos with separate reuse terms. No imagined chunks of superheavy elements are substituted for photographs.
